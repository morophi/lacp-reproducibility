# 자료 출처와 공개 처리

## 시간과 증거의 구분

- 원 생성 실험: 2026년 6월, 최종 DB는 `lacp_db_final`.
- 전수 근거 검증: 2026-09-27. CDS 응답 임베딩 재계산도 이 날짜의 기록입니다.
- 새 공개 패키지용 원격 수집: 2026-09-29. 컨트롤 노드 4개에서 읽기 전용으로 수집했습니다.
- 공개 분석 코드: 로컬 절대경로를 제거하고 저장소 상대경로를 사용하는 독자용 프로그램으로 정리했습니다. 새 정책효과 실험을 만들지 않았습니다.

원격 수집 UTC 시각, OS 관측값과 DB 스냅샷 정보는 [collection.json](../provenance/collection.json)에 있습니다. 수집 시점의 OS를 원 실험 당시 환경의 완전한 지문으로 해석하지 않습니다.

## 원본과 공개본 해시

[artifacts.json](../provenance/artifacts.json)의 각 항목은 다음을 기록합니다.

| 필드 | 의미 |
|---|---|
| node / source_path | 수집 노드·원본의 상대경로 또는 로컬 감사 자료 경로 |
| published_path | 저장소에서 볼 수 있는 경로 |
| original_sha256 | 노드 원본의 해시. 예전 공개 처리본을 이용한 역사적 설정은 기존 수집 manifest의 원본 해시를 계승 |
| published_content_sha256 | 공개 내용의 해시, gzip이면 압축 해제 후 기준 |
| stored_sha256 | 저장소에 실제 들어간 파일 바이트의 해시 |
| transformed | 이번 공개 처리에서 내용이 바뀌었는지. 기존 감사에서 이미 정리한 파일의 추가 변환 여부와 원본 해시는 별개 |
| gzip | 압축 저장 여부 |

`transformed=false`라도 과거 감사에서 이미 비밀정보를 제거한 역사적 설정은 원격 원본 해시와 다를 수 있습니다. 각 해시의 역할을 구분하십시오. 원래 node_config의 해시가 DB 실행에 연결되는지는 [formal_config_hash_links.csv](../results/published/formal_config_hash_links.csv)로 확인합니다.

## 공개를 위해 바꾼 것

- 내부 운영 IP를 역할 호스트 이름으로 바꾸었습니다. CSV·JSONL의 `physical_node_url` 등에도 같은 치환을 적용했습니다.
- 실행 코드의 개인 홈 경로를 `/home/lacp`로 치환했습니다. 실제 설치 환경에 맞게 수정해야 하는 예시 경로입니다.
- 실제 인증정보가 든 dotfile, SSH 키·개인 설정·가상환경·캐시를 수집 대상으로 삼지 않았습니다. 설정의 비밀번호는 환경변수 참조 또는 기존 `[REDACTED]` 표기입니다.
- 운영 삭제·임시 진단 스크립트, 중복된 서버 가상환경과 대형 Chroma DB 파일은 공개 재현에 필요하지 않아 제외했습니다. 동결 청크·행렬·실제 검색 문맥을 제공합니다.
- 라이브 노드에 남지 않은 실험 시점 프롬프트·설정의 일부는 9월 27일 검증 사본에서 가져왔으며 `archive_20260927`로 표시합니다.

수집한 원 DB 6개 테이블과 145개 실제 검색 문맥은 이전 검증본과 동일했습니다. 운영 식별정보 치환 후 공개 자료로 지표·입력·결과표 재현을 통과했습니다. 과학적 해시를 새 값으로 덮어 쓰지 않았습니다.

## 읽기 쉬운 결과와 전수 자료

`results/reference/`는 기존 논문 수치의 기준표, `results/published/`는 새 공개 자료에서 실행한 결과, `evidence/audit_20260927/`은 당시 상세 점검 증거입니다. `provenance/SHA256SUMS`는 그 파일 자체와 `.git/`, 독자 생성 폴더를 제외한 공개 파일 전체의 체크섬입니다.

과거 GitHub 저장소의 백업은 공개 패키지 밖의 로컬에만 보관했으며 새 이력에 포함하지 않았습니다. 구 저장소의 파일 구성을 가져온 것이 아니라 현재 노드와 논문 근거에서 새로 구성했습니다.
