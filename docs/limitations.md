# 확인된 범위와 남은 한계

## 확인한 것

- 현재 최종 DB 6개 기본 테이블은 9월 27일 검증본과 바이트 단위로 같습니다. 그 검증에서는 6월 30일 보관본과의 동일성도 확인했습니다.
- formal+accepted 80회·7,200응답의 MA/SRR/SCI와 LMS 저장 배열 집계를 재현합니다.
- 원천 행렬에서 CDS 참조를 재생성하고 파일 해시까지 대조합니다.
- 9월 27일 보관 모델을 사용한 CDS 응답별 재계산 기록은 7,200행의 저장 점수와 일치합니다. 기본 독자 명령은 그 기록의 대조입니다.
- 재구성한 입력·정책문구 해시, Run B 트리거, CR2 동결 임계값 및 논문 주요 결과표를 확인합니다.

## 확보하지 못했거나 구별해야 할 것

1. **LMS 원시 후보 전체·토큰 문자열:** entropy·선택 margin 배열부터 집계하는 범위까지입니다. 전체 후보의 점수부터 재계산한 것이 아닙니다.
2. **생성 모델 digest:** 분석 대상 7,200행의 digest가 공란입니다. 모델 alias만으로 당시 가중치를 고정할 수 없습니다.
3. **전체 배포 지문:** DB의 harness_version·metric_pipeline_version이 공란입니다. 파일별 해시 증거와 전체 환경의 완전 식별은 다릅니다.
4. **별도 6월 18일 재보정 원본:** 동결값과 로그에서 수치를 재구성했지만 당시 별도 감사·출력 파일의 완전한 원본 이력은 확보하지 못했습니다.
5. **정식 A/B 교차배정:** 원래 노드·역할·경로를 분리하는 검증된 교차실험은 없습니다.
6. **CF-F의 추가 차이:** 지정 턴 RAG/RBC 외에 공통 언어 지시가 바뀌었습니다. 재시도 0회가 언어 지시의 효과 부재를 의미하지 않습니다.
7. **민감도:** max 임계값 대안은 기존 응답 이력을 고정한 사후 배정 비교입니다. 대안으로 처음부터 실행했을 때의 후속 결과가 아닙니다.
8. **내용 정확성·제도 성과:** 문자열·구조 지표가 정책적 정확성, 실제 행정 책임성, 시민의 권리구제 성과를 대신하지 않습니다.
9. **반복의 독립성:** 동일 30질문·동일 설정의 반복입니다. 최빈 응답 일치율을 정확도·사고 확률 또는 서로 독립인 2,700사례로 해석하지 않습니다.
10. **수집 범위:** 이번에는 컨트롤 노드 4개만 읽었고 추론 노드·다른 개인 기기에는 접속하지 않았습니다.

## 기존 이력 교체의 기술적 범위

공개 저장소는 부모 커밋이 없는 새 최초 커밋으로 시작합니다. 기존 커밋을 참조하는 브랜치·태그를 남기지 않습니다. 과거 버전에서 복제한 작업본을 병합하면 이전 이력이 다시 들어올 수 있으므로 새로 clone해야 합니다.

GitHub 내부의 오래된 객체·캐시와 타인의 clone/fork까지 제거했다는 뜻은 아닙니다. GitHub는 해시를 통한 캐시 접근과 외부 복제본의 한계를 [공식 문서](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)에 설명합니다. 이번 과학적 자료 공개를 GitHub 내부 보존 데이터의 완전 소거로 표현하지 않습니다.
