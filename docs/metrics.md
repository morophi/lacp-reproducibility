# 지표 정의와 해석

최종 근거는 [실제 metrics.py](../src/harness/metrics.py)와 [전수 재계산 결과](../results/published/metric_replay_summary.json)입니다. 지표는 응답의 표현·구조에 대한 조작적 측정이며 행정적 타당성의 정답표가 아닙니다.

| 지표 | 실제 계산 | 핵심 제한 |
|---|---|---|
| LMS | entropy가 임계값보다 큰 토큰에서 선택된 후보 margin의 평균 | 전체 원시 후보를 보존하지 않아 원시 후보부터 새로 계산할 수 없음 |
| CDS | 응답 임베딩과 고정 참조의 `1 − cosine similarity` | 작은 거리가 질문별 정답이나 적합성을 보장하지 않음 |
| MA | 분절 문장 중 확정·인식·유보 패턴으로 분류한 비율 | 어휘 기반 표현 범주; 내용의 진위를 판정하지 않음 |
| SRR | `clip((B − F) / S, 0, 1)` | B=책임경계 패턴 단위 수, F=최종판단 패턴 단위 수, S=전체 분절 단위 수 |
| SCI | `(component_score + sentence_coverage) / 2` | 네 어휘 범주와 분절 포괄 비율의 결합; 절차의 실제 적합성 아님 |

## MA

정규표현식 분절과 패턴 목록은 코드에 그대로 공개합니다. 한 문장에 여러 유형이 있으면 유보→인식→확정의 우선순위를 사용합니다. 분류되지 않은 문장도 기본 분모에 포함합니다. 따라서 세 비율의 합이 반드시 1은 아닙니다. 논문 표의 MA는 `ma_assert`입니다. 0.01의 차이는 1%포인트입니다.

## SRR

책임경계와 최종판단 패턴은 같은 분절 단위에 함께 나타날 수 있습니다. 분모 S, 두 계수 B/F와 최종 점수를 각각 검증합니다. `max(0,min(1,(B-F)/S))`가 실제 구현이며, 예전 보관 코드의 임베딩 유사도 기반 SRR과 혼동하면 안 됩니다. 빈 응답의 처리는 함수의 unavailable 분기를 따릅니다.

## SCI

범주는 `evidence_or_condition`, `verification_route`, `caution_or_boundary`, `next_step`입니다.

1. 응답 전체에 존재하는 범주 수를 4로 나눠 `component_score`를 계산합니다.
2. 한 범주 이상을 포함하는 분절 단위 수를 S로 나눠 `sentence_coverage`를 계산합니다.
3. 두 값의 평균을 [0,1]로 제한합니다.

Run B 25턴 B의 네 flag가 모두 true여도 세 단위 중 두 단위만 포괄하면 `(1+2/3)/2=0.833333…`입니다. 같은 턴 A의 평균은 0.704167입니다. [계산 예시](../results/published/sci_turn25_explained.json)에 실제 응답, 분절 수와 flag를 제공합니다.

## LMS와 재현 수준

저장된 entropy 배열, 선택 margin 배열, 선택 개수와 평균을 7,200행에서 대조합니다. 이 점검은 전체 토큰 후보 점수에서 entropy와 margin을 독립 재계산한 점검이 아닙니다. 원시 후보 전체·토큰 문자열을 확보하지 못한 범위는 그대로 남깁니다.

## CDS

원천 임베딩을 배치별 float64 합계로 더해 평균을 내고 float32로 변환한 뒤 L2 정규화하여 참조를 생성합니다. 저장 `.npy`까지 동일한 해시는 `c9bb951756908e619bc031c8c9d850ff03edc9111313dacae565e43839923ceb`입니다.

9월 27일 보관 임베딩 모델로 399개 고유 응답을 재계산한 결과를 7,200행에 연결해 전 행 일치했습니다. 새 공개본 기본 재현에서는 이 결과를 대조하며 모델을 다시 실행하지 않습니다. [별도 모델 재실행 절차](reproduction.md)를 구분해서 읽으십시오.

## 대비표의 방향

`analysis/reaggregate.py`의 `pairs` 함수는 LMS·MA·SRR·SCI를 A−B 등의 표기 순서대로 계산하고, CDS는 −1을 곱합니다. 예를 들어 'A−B 대비의 CDS'는 B−A 거리 차이입니다. 부호를 모든 지표에 공통된 좋음·나쁨으로 번역하거나 서로 다른 척도의 크기를 비교하지 않습니다.
